## 三、实现中发现并修掉的真问题

1. **网格被配色底盖掉（视觉回归）**：新增的 `.g-bg-base` 是 `z-index:-4` 的不透明 fixed 层，原来挂在 `body` 上的 8px 网格被整片遮住。按规格 §1.7 把网格提为独立固定层 `.g-bg-grid`；`px-grid` 主体生效时再关掉它，避免同一位置画两遍线。
2. **`--g-line` 作为输入框边界只有 1.1–1.2:1**：新增 `--g-line-hi`（四套配色各自 ≥3:1）并把它用到输入框/文本域/`select`。
3. **警示横幅白字读不清**：`s4-auth.css` 把 `.g-demo-banner` 文字硬编码成 `#fff`，在 `--g-warning(#ffb347)` 上只有 1.7:1。改为 `--g-on-warning`（深色字），仅 P2 浅底保留白字。
4. **全屏截图里的「白底网格」是拼接伪影**：`fullPage` 截图会把 fixed 层按段拼接。真实视口下（`.tmp/shots/h0–h2.png`）层叠正确，已用 `getBoundingClientRect` 复核四层都是 1440×900。
5. **P2 纸面上的星空太脏**：把星点压到 `opacity .18` 并改用墨色调，既保留纹理又不脏版。
6. **脚注里用了原生 `<a href="/privacy">`**：HashRouter 下会跳出 SPA，已改 `Link`。
7. **照片背景看不见**：纯按规格的压暗（α .62–.86）会让照片几乎隐形。保留规格默认值（保证 AA），另加「照片可见度」系数，并把实时对比度贴在界面上。
