## 四、关键决策（含理由，别推翻）

1. **自托管 PostgreSQL，不用 Supabase**（用户明确要求）。
2. **安全三层**：`app_user` 非超管 + 每请求同一事务内 `set_config('app.user_id', ...)` + 所有查询走 `withRls()`；用户私有数据禁止 `withSystem()`。
3. **RLS 之外再加 security definer 函数**（0015 起）：把「谁能读 `auth.users` / `phone_verifications`」彻底收口到函数里，表上不给 `app_user` 直接权限。
4. **会话形态**：JWT access + 服务端 `security_sessions` 可撤销 + HttpOnly Cookie；不把会话写 localStorage（只存 `gy:token` 给 api 模式）。
5. **注册安全**：短信验证码（`SmsSender` 可插拔，生产 aliyun）+ Turnstile + 限流 + 协议版本化同意。
6. **排序确定性**：不用 `localeCompare`，数据库不依赖默认 collation → 名称并列一律 `collate "C"`，前端用 `compareLabel()`。**CI 曾因此变红**（Windows 中文系统按拼音、CI 按码位）。
7. **图片**：本地磁盘 `IMAGE_ROOT` + `/images` 静态；key 不可猜测；`photos.image_key` 恒等于组照 position 0（这条不变式让列表/详情/存储清理零改动）。
8. **主题/活动（8.4d）**：编辑评选（**不做**用户投票、赛事、商业化）；同一时刻只有一个 `active` 主题（部分唯一索引做成数据库事实）；每人每主题最多 3 件；已精选不可由作者撤回；精选发 `system` 通知。
9. **测试纪律**：一次性库 + 全部迁移 + 全套件（`.tmp/verify-fresh-db.sh`）才算数；**常用库上不要连跑两套**（会互相污染出假失败）。
10. **API 哈枞跑的是 `server/dist`**：改后端必须 `pnpm build` 重建，否则浏览器套件测到旧代码（曾因此误判 404）。
11. **部署节奏**：每点做完 → 自检 → **经用户同意**才推送/部署。

## 五、踩过的坑（一定会再遇到）

1. 含中文的 SQL 必须写 UTF-8 文件用 `psql -f`，并设 `PGCLIENTENCODING=UTF8` + 文件首行 `\encoding UTF8`；`-c` 会被控制台 GBK 弄坏。
2. `psql` 不带 `PGPASSWORD` 会卡在密码提示，把后台任务挂死。
3. 迁移幂等：`create or replace function`（**不要 `drop function`**，会连带丢 grant；确需 drop 时必须补回 revoke + grant）；`drop trigger` 必须在 `drop function` 之前。
4. `supabase/verify-schema.sh` 带期望值，新增表/迁移要同步更新，否则它构造的库不是应用里的库。
5. 集成测试的字符串里**不要用 `%`**（会变成 pg 参数占位符）。
6. 种子必须先插 `auth.users`（`profiles.id` 外键指向它），由触发器建 profile。
7. `@fastify/rate-limit` 默认 500 会漏出去 → 用户可见的限流拒绝必须 429 `RATE_LIMIT`。
8. 签名/cookie 密钥短于 32 字符会让 `signCookie` 抛错，表现为 **500 而不是 400**。
9. Windows 上 esbuild 处理 >1 MiB 输入会写 `%TEMP%` 再删除失败 → 生产构建必须 `TEMP=.tmp/esbuild-tmp TMP=...`。
10. `vite dev` 只绑 IPv6 回环，`curl` 要用 `localhost` 而不是 `127.0.0.1`。
11. Playwright strict mode：页面上同名文本必须 `exact: true`。
12. 通知断言用**显示名**（`API Other`）不是登录名（`api_other`）。
13. 套件之间不要共享会被改状态的作品（`photo-owner` 会把作品撤回成 `removed`）。
14. 测试脚本用 `set -euo pipefail` + `ON_ERROR_STOP=1`，**不要把输出管道给 `tail`**（吞掉退出码）。
15. `git commit` 中文提交信息写文件用 `-F`（命令行参数会被 GBK 弄坏）。
